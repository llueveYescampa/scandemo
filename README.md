# scandemo: 
A program to test ObjectScan

Version 1.0

November 04, 2026

Welcome to **scandemo**. Thank you for using it! 

# Requirements

- `C++ compiler`
- `cmake`

# Build Instructions

1. Make a build directory

```bash
mkdir build 
```

2. move to the build directory
```bash
cd build 
```

3. Build scandemo
```bash
cmake ..
```

4. Make scandemo
```bash
make 
```
